# Photocatalytic Tile Study Data and Analysis

This repository accompanies the preliminary study of an experimental TiO2-based composite tile under covered and natural-sunlight-exposed conditions. It contains the original MQ-3 sensor CSV records, a small analysis script, processed summary statistics, and the current manuscript files.

## Study summary

An MQ-3 alcohol-sensitive sensor recorded raw ADC response during one covered run and one natural-sunlight-exposed run using liquid isopropyl alcohol (IPA) as the vapour source. The sensor was not calibrated to IPA concentration. The records therefore show electrical response, not IPA concentration or removal efficiency.

The manuscript reports a 1.19% decrease between the means of the first and final 10% of readings in the covered run and a 20.45% decrease in the sunlight-exposed run. The sunlight trace first rose and then declined. These are within-run signal changes from one run per condition; they do not establish photocatalytic removal. Run durations differed, and irradiance, temperature, humidity, and reaction products were not measured.

## Repository structure

- `data/raw_data/`: copies of the two original CSV files; the original files are preserved without editing.
- `data/processed_data/`: summary statistics generated by the script and a data dictionary.
- `code/analysis_scripts/`: a Python 3 analysis script using only the standard library.
- `results/figures/`: vector SVG plots generated from the raw data.
- `paper/`: revised manuscript PDF and citation files for adding the repository link after upload.

## Reproduce the summary and figures

From the repository root, run:

```text
python code/analysis_scripts/analyze_sensor_data.py
```

The script writes `data/processed_data/summary_statistics.csv`, `results/figures/mq3_sensor_response.svg`, and `results/figures/initial_final_10_percent_means.svg`.

## Data interpretation and limitations

`mq3_raw` is the recorded raw ADC value. `mq3_voltage` is the sensor-output voltage recorded in the source CSV. Neither column is a calibrated IPA concentration. The two traces are not matched replicates, and the observed decline may be affected by IPA evaporation/source depletion, adsorption, air exchange, sensor drift, or environmental changes. The available records do not separate these effects from photocatalytic transformation.

The formulation recorded for one tile was approximately 4-6 g anatase TiO2, 2-3 g urea, 0.05-0.1 g graphite, and 0.5-1 g iron oxide, with sodium silicate as binder. TiO2 and urea were heated separately before mixing. Heating conditions and several other preparation/test details were not available in the source record. The coating was tested as a whole; ingredient-specific effects were not isolated.
